# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [4.0.0] — не выпущена

Пакет переписан: отдельный проект без зависимостей, свой интерфейс, безопасный API.

### Несовместимые изменения

- Пакет больше не требует CMS: свои запрос (`Simflex\FileManager\Request`), ошибка (`ApiException`) и JSON-ответ.
  Автозагрузка — только `Simflex\FileManager\` (`src/FileManager/`). Конструктор:
  `new Manager($root, $authFn, $csrfFn = null, $request = null)` — запрос по умолчанию берётся из `$_GET`,
  `$_POST`, `$_FILES`, `$_SERVER` (`Request::fromGlobals()`).
- Ответ API — `{"error": {"code": 0, "message": ""}, ...}`: списки (`getTree`, `getFileList`, статусы `upload`)
  — в `items`. Ошибка — HTTP-статус (401, 403, 404, 405, 409, 413, 422, 500), `error.code` равен статусу,
  `error.message` — текст для пользователя. Вместо `success` и кодов вида `not_authenticated`.
- Изменяющие методы (`delete`, `createDir`, `rename`, `move`, `upload`) — только POST (иначе 405) со страницы этого
  же сайта (`Sec-Fetch-Site`, иначе `Origin`/`Referer`) и с CSRF-токеном, если задана проверка `$csrfFn`
  (иначе 403). Окно отправляет токен заголовком `X-CSRF-Token`.
- Сжатие при загрузке — только с согласия: окно спрашивает перед загрузкой, API сжимает при `compress=1`.
  Сжатая картинка сохраняется в WebP (`photo.jpg` → `photo.webp`).
- Окно — свой интерфейс без компонентов страницы: `<dialog>`, свои меню, подсказка, подтверждение
  и уведомления, стили — `src/assets/styles/file-manager.css` (классы `fm-*`, токены `--fm-*`). Шаблон
  `src/tpl/index.tpl` получает переменные (`$fileManagerApi`, `$fileManagerRoot`, `$fileManagerAssets`, `$theme`,
  `$fileManagerCsrfToken`, `$fileManagerProtectedDirs`) вместо глобальных `fileManager.apiBase`, `rootDir`,
  `assetsDir`. Скрипт — ES-модуль без jQuery.
- Защищённые методы переименованы: `subdirectories()` → `getSubdirectories()`, `fixFilesArray()` →
  `getUploadedFiles()`.
- Удалены старые сборки (`src/assets/css/*`, `src/assets/js/app.js`, `app.min.js`), картинки-заглушки и пример
  `bootstrap.php`.

### Добавлено

- `window.fileManager.open({multiple, accept, select, onSelect, onCancel})` возвращает Promise: файлы
  `[{path, url, name, isImage}]` по «Готово» или `null` при любом закрытии без выбора. На одно открытие — ровно
  один ответ; `open()` при открытом окне отменяет прежний вызов. `accept` — расширения (`['jpg', 'png']`) или
  строка как у `<input type=file accept>` (`'image/*,.pdf'`): неподходящие файлы видны, но не выбираются и не
  загружаются. `select: true` — режим выбора без `onSelect`.
- Перемещение файлов и папок: пункт меню и метод `move` (`path` — папка назначения, `items[]` — пути). Папка
  назначения выбирается по шагам; папку нельзя переместить в неё саму, занятое имя — 409.
- Режим отметки нескольких файлов: галочка на карточке, Ctrl/⌘, Shift, пробел; дальше клик отмечает, «Отменить
  выбор» — выход. На телефоне — «Выбрать» в меню по долгому нажатию.
- Сжатие при загрузке: JPEG, PNG, WebP — в WebP до 2560 px (GD), видео — в MP4 H.264 до 1920 px (ffmpeg: `FM_FFMPEG`
  или `ffmpeg` в `PATH`). Сжатый файл остаётся, только если он легче или уменьшен. Метод `compression` — что
  сервер умеет сжимать. Настройка — константы `COMPRESSED_IMAGES`, `IMAGE_MAX_SIDE`, `IMAGE_QUALITY`,
  `COMPRESSED_VIDEOS`, `VIDEO_MAX_SIDE`, `VIDEO_CRF`.
- Предупреждение о ссылках на файл: `setUsageFinder(fn(string $url): array, '/uploads')` — сайт ищет, где стоит
  адрес файла, метод `usage` отдаёт `[{table, count}]`. Окна удаления, переименования и перемещения показывают
  предупреждение, а кнопку действия делают доступной, только когда поиск закончился.
- Системные папки: `setProtectedDirs(['/images'])` — их нельзя удалить, переименовать, переместить и отметить.
- `process()` — ответ API без отправки (`[статус, тело]`), `setErrorLogger()` — куда писать внутренние ошибки.
- Дерево папок подгружается по уровням (`getTree` с `depth=1`, `has_children`); переход в папку раскрывает её.
- Имена загруженных файлов — латиницей («Фото отпуска.JPG» → `foto-otpuska.webp`), без перезаписи (`photo-2.webp`).
- Мобильная версия (список, нижняя панель, окна-шторки над экранной клавиатурой), тёмная тема
  (`data-fm-theme="dark"`), плавные переходы, полосы прокрутки, клавиатура (стрелки, Enter, Delete, Esc).
- Скачивание потоком, с `Content-Length` и именем в UTF-8.
- Уведомления — колодой: новое спереди, прежние (до трёх) чуть меньше выглядывают сверху, при наведении мыши
  стопка раскрывается списком и время закрытия встаёт на паузу; у обычных — полоска оставшегося времени.
  Повтор того же сообщения не добавляет новое, а продлевает прежнее. Нет связи с сервером — «Нет связи с
  сервером…» вместо «Failed to fetch».
- Сортировка: по дате — новые первыми, по весу — тяжёлые первыми, папки по весу — по числу элементов; равные
  по дате или весу — по названию (порядок не прыгает).
- У всех кнопок видно нажатие (серые кнопки, путь, сортировка, галочка, выбранная карточка).

### Безопасность

- Путь разбирается одной проверкой: начинается с `/`, без `.`, `..`, `\` и нулевого байта, не проходит через
  символические ссылки и не выходит из корня. Корень нельзя удалить, переименовать и переместить.
- Удаление папки не заходит в символические ссылки внутри неё.
- Загружаются только файлы из белого списка расширений (`ALLOWED_EXTENSIONS`), без исполняемых частей в имени
  (`file.php.jpg`); картинки, которые хранятся как есть (GIF, AVIF, BMP, ICO, TIFF, HEIC), с HTML, скриптом или PHP
  внутри не принимаются.
- Ответы — с `Cache-Control: no-store`.
- Подтверждение удаления называет, что удалится; Delete удаляет карточку под фокусом; отмеченное, скрытое
  поиском, не удаляется.

### Переход с прежних версий

1. Обработчик API: `$manager = new \Simflex\FileManager\Manager($uploadsDir, $authFn, $csrfFn);
   $manager->handleRequest();` — изменяющие запросы теперь только POST с токеном.
2. Окно: вывести `src/tpl/index.tpl` с переменными (см. README), подключить `src/assets/js/file-manager.js` как модуль.
3. Свои вызовы API — перейти на конверт `error`/`items` и POST для изменений.
